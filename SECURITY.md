# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The CVUT team takes software security seriously, especially given our focus on intercepting low-level system binaries and GPU driver calls.

If you discover a security vulnerability, memory safety bug in unmanaged translation, or privilege boundary issue in CVUT, please report it responsibly:

1. **Do NOT** open a public GitHub issue.
2. Email security reports to the maintainers or report via GitHub Private Vulnerability Reporting at:
   `https://github.com/timfromhcs/cvut/security/advisories/new`
3. Include detailed reproduction steps, minimal reproducer code, target platform, and affected GPU driver.

Maintainers will acknowledge receipt within 48 hours and coordinate a disclosure timeline and patch release.
